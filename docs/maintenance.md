# 长期维护计划

## 范围

- Codex 按实际返回窗口展示，Pro 单周、Plus 5h＋周、空值及缓存状态。
- DeepSeek 官方余额、多币种、无凭据、网络失败和鉴权失败。
- 深色主面板、详情子菜单、刷新与退出区域一致性。
- 公开仓库版本索引、说明、演示图库、检查脚本、固定源码下载和 Release。

## 执行流程

用户反馈随时处理；维护时先检查工作区、上次记录和 origin/main。复现明确问题后最小修复，不为维护节奏新增功能。新增定时执行需单独配置；本文件不代表已经安排自动周检。

执行 `bash scripts/check.sh`、`python3 scripts/check_public.py`，可见改动运行 `python3 scripts/render_gallery.py` 并查看图像。可联网运行应用核对真实接口，但不把私人结果写进仓库。安装成功、编译通过、离屏绘图分别记录，不能等同完整桌面验收。

发布前与上一公开版本比较，敏感检查后提交，上传后核对远端树。创建不可变标签与 Release，确认 ZIP 和图库可访问。无产品变化不创建 Release。

## 当前验收边界：v0.11.0

已实现 DeepSeek 余额独立刷新、分段额度条、暗色卡片和底部原生菜单深色外观；详情仍可查看最近任务、重置时间和重置券。

已知限制：依赖 Codex 本地非稳定 app-server 与 state_5.sqlite；切换账号后旧后台服务可能暂存旧身份，现有缓存未按账号隔离。需要改善后台生命周期、账号切换缓存隔离及无凭据时隐藏可选服务的体验。不得为本次维护文档宣称这些问题已修复。

下轮重点：账号切换、长错误文本、低分辨率屏幕、多显示器、键盘导航和 VoiceOver 验证。版本验收结果见 CHANGELOG。
